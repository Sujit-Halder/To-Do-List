# To-Do-List

This is a nice app to add any task you like to do later and it will give you remainder via SMS and Email before 1 hour if you have scheduled your task to be greater than one hour.

It provide a dedicated section for TO-DO list with nearest task in the top.

Also a dedicated section for any task that has been completed or overdued.

And a section to show progess of all scheduled task.


There is a way to organise different task in to a tasklist in your wise and there you can add any number of tasks.Selecting that from left basr will render corresponding list's task on TO-DO 

and in completed task section.

There is multiple way of filtering, sorting in any order.


**It is a user based webapp with jwt token.
It is not hosted but you can download and host it your device.**
